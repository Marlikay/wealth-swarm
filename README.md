# Wealth Swarm Crypto Trading Platform

## Overview
This is the complete Wealth Swarm crypto trading platform, including all necessary components for both backend and frontend.

## Structure
- **backend/**: All server-side code and configurations.
- **frontend/**: All client-side code and configurations.

## Installation
1. Clone the repo.
2. Set up environment variables in `.env` and `.env.local`.
3. Run `docker-compose up` to start the app.

## Technologies Used
- Node.js
- Next.js
- TypeScript
- Tailwind CSS
- MongoDB
- Docker

## Features
- User authentication and authorization
- Wallet management
- Real-time trade execution
- Admin dashboard
